# Cover Letter Retro (`/cl-retro`)

Every manual edit you make to a cover letter before sending it is high-signal telemetry about your voice and judgment. `/cl-retro` captures those edits so you never have to fix the same phrase twice.

## Table of Contents

- [1. Diff Final Letter Against Agent Draft](#1-diff-final-letter-against-agent-draft)
- [2. Classify Each Edit by Signal Type](#2-classify-each-edit-by-signal-type)
- [3. Update `vault/voice-profile.md` & `vault/career-quarry.md`](#3-update-vaultvoice-profilemd--vaultcareer-quarrymd)

---

## 1. Diff Final Letter Against Agent Draft

Compare the user's final edited `cover-letter.md` (or pasted submission text) against the earlier draft generated by `/cl-draft`.

---

## 2. Classify Each Edit by Signal Type

Group every change into one of three categories:
1. **Voice & Syntax Compression**: Words the user cut, shortened, or replaced because they sounded stiff, corporate, or unnatural.
2. **Factual Nuance / Boundary Refinement**: Adjustments to how a project, metric, or tool was framed to be more accurate.
3. **Strategic Emphasis**: Shifts in which proof point or hook led the paragraph.

---

## 3. Update `vault/voice-profile.md` & `vault/career-quarry.md`

1. Propose concrete additions to the **Banned Slop Registry** or **Preferred Syntactic Patterns** in `vault/voice-profile.md`.
2. If the user refined a project description, propose updating the corresponding `STORY-*` record in `vault/career-quarry.md`.
3. Apply the approved updates to disk and log the retro summary.
