# Kageyoni v11 Qualification Contract

## Frozen build target

Kageyoni v11 targets **mechanical trustworthiness**. Promotion requires that authoritative engine state corresponds to demonstrated authorization, execution, observation, verification, and recovery within the tested boundaries.

## Release gate

1. No known mechanical trust scar remains reproducible.
2. Repair-derived attacks reveal no new material mechanical failure class after saturation.
3. Valid neighboring behavior remains possible.
4. Mutation tests demonstrate critical safeguards are causally exercised.
5. Inherited regression behavior remains green except explicitly reviewed version-contract changes.
6. Packaged/installable source matches the exact qualified source.
7. Trust infrastructure does not silently alter canonical world state during migration.

Semantic competence, universal transfer, professional expertise, and Pirate King-level benefit are downstream evaluations, not v11 release requirements.
