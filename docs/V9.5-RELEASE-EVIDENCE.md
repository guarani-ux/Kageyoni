## Campaign and installation

`evidence/v4-v8-campaign-integration.json` records the real revision-60 campaign upgrade through migration 017, all 101 preexisting non-version tables unchanged, Sciel's identity and decision fingerprints preserved, and identical installed/restored table contents. The campaign still contains 60 events and 237 records. New activity tables remain empty; the new coordination identity represents the engine itself.

`evidence/v9.5-installed-wheel.json` records an isolated installation outside the source tree, fresh migration through 017, all SQL resources included, 78 resolvable guided action signatures, persisted settings and successful verification. No runtime dependency or model API is required. Tested interpreter: Python 3.12.14; the declared minimum is Python 3.10, not a claim of a complete cross-platform interpreter matrix.

`docs/V4-V8-REVIEW.md` records 16 independently authored boundary tests and the distinction between reproduced defects and issues fixed during source review. The final cumulative regression passes **397 tests in 27.942 seconds**. The connected demonstration passes **20 controls**, with three integration tests inspecting actual saved outputs, relocation guards and corrupt-content rejection. The final cumulative regression log is `evidence/v4-v8-full-tests.txt`; it includes the earlier 293 tests and all new component, adversarial and integrated release tests.

## What remains empirical

The collective comparison uses actual current-host outputs, not prewritten stand-ins. Its frozen V3 task is historical test material; `V9.5-HANDOFF.md` is the current operational guide. C met ten requirements in one host task; D met nine with one partial in three tasks. The agent review was not blind or independent human assessment. No statistical reliability, autonomous mastery, general domain transfer, production savings or measured model-token cost is established. The proposed 32-run pilot remains future evaluation, not unfinished runtime implementation.
