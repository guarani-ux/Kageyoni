# Acceptance contract

The integrated build must provide a resumable local campaign in which properties can affect supported event stages, events persist causal history, consequences and background processes alter later state, and the agent can use structured operations without writing SQL during play.

The fixture suite is noncanonical. It covers the original A–J cases plus the coordinated-process, relevance, opportunity, compatibility, and migration cases in `REQUIREMENT-CHECKLIST.md`. Every fixture labels its evidence as noncanonical and runs in a temporary database.

The engine must preserve identity, nature, composition, agency, control, classification, capability, social role, knowledge, and history as distinct concepts. It must preserve individual intentions within collectives, distinguish freedom from power and obedience, keep unknown/zero/absent/not-applicable property states separate, and record event order separately from fictional time.

Passing means the observed behavior is enforced by the engine or proved by the named test. A stored definition, a documentation paragraph, or an unexecuted consequence does not count. Remaining judgment boundaries are listed explicitly in the checklist and evidence report.
