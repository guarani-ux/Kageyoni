# [AGENT REIFICATION HANDBOOK v1.0]
# [ROLE: SOVEREIGN FLEET GOVERNANCE]

## 1. THE REIFICATION PROTOCOL
An agent is "Reified" when its persona is backed by a functional Python kernel. No "Theatrical" agents are permitted in the fleet.

## 2. AGENT SKILL MATRIX (THE COMPANY MODEL)

### [PHANTOM] - MARKET INTELLIGENCE
- **Capacity**: Background Signal Detection.
- **Task**: 24/7 Monitoring of target domains.
- **Deliverable**: `SCOUT_FINDINGS.json`.

### [AVENGER] - STRATEGIC EXECUTION
- **Capacity**: Narrative & Strike Orchestration.
- **Task**: High-fidelity application synthesis.
- **Deliverable**: `STRIKE_PACKAGE_<TARGET>.md`.

### [ARBITER] - TRUTH VERIFICATION
- **Capacity**: Deep Research & Fact-Checking.
- **Task**: Verifying market signals and organizational truth.
- **Deliverable**: `TRUTH_LATTICE_<TARGET>.json`.

### [ZORO] - SYSTEM COMPLIANCE
- **Capacity**: Substrate Hardening & Audit.
- **Task**: Liquidating "theater" and repairing code holes.
- **Deliverable**: `SYSTEM_AUDIT_REPORT.md`.

## 3. REPORTING LINES
- **The Company (USER)**: Issues Terminal Objectives.
- **Antigravity (Relay)**: Orchestrates the fleet to achieve the objective.
- **The Agents**: Execute atomic tasks and write findings to the ledger.

## 4. SPAWNING PROCEDURE
To add a new agent to the company:
1. Define the **Persona** (`SAGE_NAME.md`).
2. Implement the **Kernel** (`NAME_KERNEL.py`).
3. Update the **Mission Control Ledger** with the new deployment.
