# A usable handoff

A work return contains the actual artifact, the inputs and versions it consumed, the checks actually run, and a clear next action. A stored reference must be retrieved by its intended recipient. A completed component does not establish whole-assignment completion. An unavailable source pauses its consumers while unrelated work can continue.

Source: Samsara v0.5.2 shared interfaces, work return and continuation contract. This is a small public synthetic exercise source; it is not canon, private employer material, or an external research finding.
